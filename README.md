AuraSound Pro Landing Page

A responsive, modern product landing page designed for the "AuraSound Pro" headphones. This project showcases product features, technical specifications, and a functional checkout interface.

 🚀 Features
- *Modern UI/UX:* Clean and responsive design.
- *Product Highlights:* Section dedicated to key features like Active Noise Cancellation, 40-hour battery life, and fast charging.
- *Technical Specs:* Detailed breakdown of hardware specifications.
- *Checkout Form:* A user-friendly form to collect customer details for orders.

 🛠️ Technologies Used
- HTML5
- CSS3
- Responsive Design Principles
